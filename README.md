# Бот-квиз: какой продукт нужен бизнесу

Пять вопросов в Telegram, и бот советует: бот, сайт, мини-апп или связку. Затем предлагает оставить номер, и заявка уходит вам.

**Что показывает клиенту:** как бот сам ведёт диалог и приносит заявки. Подходит как первый контакт с аудиторией.

## Что внутри
- Вопросы и баллы в `src/quiz.ts`: меняйте тексты и вес ответов без правки логики
- Одно сообщение редактируется на месте, есть прогресс-бар
- Защита от двойных тапов и старых сообщений
- Номер принимается только свой (кнопка «Поделиться номером»)
- Админу приходит заявка с результатом квиза, `/stats` показывает воронку: начали, дошли до конца, заявки

## Запуск
```bash
npm install
cp .env.example .env     # BOT_TOKEN, ADMIN_CHAT_ID
npm start
```
Тесты: `npm test`. Бот работает на long polling, поэтому отдельный домен не нужен.

> Хранилище JSON подходит для демо. Для продакшена замените на PostgreSQL.
